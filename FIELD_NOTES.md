# TSG Labs Build Exercise — Deployment Field Notes

> Start using this file from the first real build/deployment issue.
>
> **Do not manufacture problems.**
> Short, specific notes about genuine issues are more valuable than a long artificial list.

---

## How to use this file

For every meaningful problem, copy the template below and fill it in **while the issue is fresh**.

Capture:
- what actually happened;
- the exact error message where useful;
- what you suspected;
- what you checked;
- the real root cause;
- how you fixed/worked around it;
- one concrete improvement Chord/docs/API could make.
